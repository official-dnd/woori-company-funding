# 우리회사도 자금

정책자금 컨설팅 랜딩페이지. HTML, CSS, JavaScript로 구성되어 별도 빌드 없이 실행할 수 있습니다.

## 실행

`index.html`을 브라우저에서 열거나, 이 폴더에서 다음 명령을 실행합니다.

```sh
python -m http.server 4174 --bind 127.0.0.1
```

접속 주소: http://127.0.0.1:4174

## 기능

- 반응형 히어로 슬라이더와 업종별 카드
- 정책자금 규모와 성공사례 영역
- 사업 정보·매출·부결 이력 입력
- 매출의 30% 참고 금액 계산
- 카카오채널 안내와 상담 일정 선택
- 평일 09, 10, 11, 14, 15, 16, 17시 예약 슬롯

실제 카카오채널 및 상담 접수 서버는 연결되어 있지 않습니다. 입력 정보는 브라우저 메모리에만 유지되며 새로고침하면 초기화됩니다. 실제 대출 심사나 한도 조회를 수행하지 않습니다.

## 파일

- `index.html`: 페이지 구성
- `style.css`: 반응형 스타일
- `app.js`: 입력 및 예약 흐름, 슬라이더
- `manufacturing.png`, `retail.png`, `service.png`, `consulting.png`: 제작한 업종 이미지
- `hero-reference-*.png`, `hero-mobile-*.png`: 제공 레퍼런스의 히어로 이미지
- `reference-success.png`, `reference-amount.png`: 사용자 제공 섹션 이미지

외부 레퍼런스 자산과 문구가 포함되어 있습니다. 원 출처는 IBK기업은행 정책자금 페이지이며 이 저장소는 해당 자산에 대한 소유권을 주장하지 않습니다. 정책자금 규모와 사례 문구는 제공 자료의 내용입니다.
